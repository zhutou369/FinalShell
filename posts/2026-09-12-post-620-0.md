首先，要体验 FinalShell 在 Windows 11 上的表现，我们得从安装开始。整个过程与在 Windows 10 上并没有本质区别，依旧是那么的直观和便捷。

## 常见问题与解决方案

尽管 FinalShell 在 Windows 11 上表现出色，但在实际使用中，偶尔还是会遇到一些小问题。这里我整理了一些常见的，并给出解决方案：

### 问题一：连接超时或连接失败

**现象：** 尝试连接服务器时，提示“连接超时”或“连接失败”。

**原因：** 这通常不是 FinalShell 或 Windows 11 的问题，而是网络、防火墙或服务器配置问题。
*   **网络问题：** 本地网络不稳定、服务器IP或端口错误。
*   **防火墙：** 本地 Windows 11 防火墙或服务器安全组/防火墙未开放 SSH 端口（默认为 22）。
*   **服务器负载：** 服务器负载过高，导致 SSH 服务响应慢或无响应。
*   **SSH 服务未运行：** 远程服务器的 SSH 服务（sshd）未启动。

**解决方案：**
1.  **检查网络：** 确保本地网络畅通，能 ping 通服务器 IP。
2.  **检查配置：** 仔细核对 FinalShell 中的服务器 IP、端口、用户名和密码是否正确。
3.  **检查防火墙：**
    *   **本地 Windows 11：** 确保 FinalShell 已被允许通过防火墙。
    *   **服务器端：** 检查服务器安全组（云服务商）或服务器自带防火墙（如 `firewalld` 或 `ufw`）是否开放了 SSH 端口。
4.  **尝试其他工具：** 使用 PuTTY 或 Windows 自带的 OpenSSH 客户端测试连接，以排除 FinalShell 自身问题。
5.  **重启SSH服务：** 如果能通过其他方式（如控制台）登录服务器，尝试重启 `sshd` 服务：`sudo systemctl restart sshd`。

更详细的连接超时问题排查，可以参考这篇教程：[FinalShell 连接超时问题修复](/posts/cn-finalshell-connect-timeout-fix/)。

### 问题二：字体显示异常或模糊

**现象：** 终端文字显示模糊、锯齿感强或字体间距不均匀。

**原因：**
*   **系统 DPI 缩放问题：** Windows 11 在高 DPI 屏幕下，某些应用程序的缩放可能存在兼容性问题。
*   **字体选择不当：** 选择了不适合终端显示的字体。

**解决方案：**
1.  **调整 FinalShell 字体设置：** 在 FinalShell 的“选项”->“终端”中，尝试更换字体为等宽字体（如 Consolas, Monospaced, 或前面提到的 Meslo LGS NF），并调整字体大小。
2.  **检查 Windows 11 缩放设置：**
    *   右键桌面空白处 -> “显示设置” -> “缩放与布局”，尝试将“缩放”设置为推荐值。
    *   如果问题依旧，可以尝试右键 FinalShell 快捷方式 -> “属性” -> “兼容性” -> “更改高 DPI 设置” -> 勾选“替代高 DPI 缩放行为”并选择“系统（增强）”或“应用程序”。
3.  **显卡驱动：** 确保显卡驱动是最新版本。

### 问题三：SFTP 传输中断或速度慢

**现象：** SFTP 文件传输过程中突然中断，或传输速度远低于预期。

**原因：**
*   **网络不稳定：** 本地网络或服务器网络波动。
*   **服务器负载：** 服务器 I/O 负载过高，影响文件传输。
*   **防火墙/安全组：** 服务器或本地防火墙对 SFTP 传输端口（通常与 SSH 端口相同）的限制。
*   **磁盘空间：** 服务器或本地磁盘空间不足。

**解决方案：**
1.  **检查网络连接：** 确保网络稳定，尝试 ping 服务器，观察延迟和丢包情况。
2.  **检查服务器负载：** 登录服务器，使用 `top`、`htop`、`iostat` 等命令查看服务器 CPU、内存、磁盘 I/O 负载。
3.  **检查磁盘空间：** 使用 `df -h` 命令检查服务器磁盘空间。
4.  **调整传输参数：** 某些情况下，可以尝试在 FinalShell 中调整 SFTP 的连接参数，但通常默认设置已经足够。
5.  **分批传输：** 对于大量小文件，可以先打包成一个压缩文件再传输，能提高效率。
